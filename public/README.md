# Static assets

Drop your logo here as `logo.png`. The NavBar and landing page reference
`/logo.png` (served by Next.js from this folder).

- Suggested size: 960 × 400 px (wider than tall, matches the NavBar).
- PNG with transparent background preferred; any format Next.js supports
  (PNG, JPG, WebP, SVG) will work if you update the `<Image src>` value.
